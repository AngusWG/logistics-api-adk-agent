```mermaid
        D --> F["Logistics API Client (Mocked)"]

    end

```

## 用户案例 1: 查询货运状态

```mermaid
sequenceDiagram
    participant User
    participant ADKAgent as "ADK Agent"
    participant ToolLayer as "ADK 工具层"
    participant MockAPIClient as "Mock API Client"

    User->>ADKAgent: "请帮我查一下订单 #ORDER123 的物流状态。"
    ADKAgent->>ADKAgent: "AI 模型: 理解意图: 查询订单状态"
    ADKAgent->>ToolLayer: "调用工具: check_shipping_status(order_id=""ORDER123"")"
    ToolLayer->>MockAPIClient: "执行 check_shipping_status(""ORDER123"")"
    MockAPIClient->>MockAPIClient: "模拟: 查找订单 #ORDER123 的状态"
    MockAPIClient-->>ToolLayer: "返回模拟结果: {...}"
    ToolLayer-->>ADKAgent: "收到工具结果"
    ADKAgent->>ADKAgent: "AI 模型: 转换为用户友好的回复"
    ADKAgent-->>User: "订单 #ORDER123 目前在上海中转中心，预计2024年12月15日送达。"
    
```

## 用户案例 2: 创建新货运单

```mermaid
sequenceDiagram
    participant User
    participant ADKAgent as "ADK Agent"
    participant ToolLayer as "ADK 工具层"
    participant MockAPIClient as "Mock API Client"

    User->>ADKAgent: "我想创建一个从深圳到洛杉矶的货运单。"
    ADKAgent->>ADKAgent: "AI 模型: 理解意图: 创建新货运单"
    ADKAgent->>ToolLayer: "调用工具: create_new_shipment(origin=""Shenzhen"", destination=""Los Angeles"")"
    ToolLayer->>MockAPIClient: "执行 create_new_shipment(""Shenzhen"", ""Los Angeles"")"
    MockAPIClient->>MockAPIClient: "模拟: 生成一个新的货运单号"
    MockAPIClient-->>ToolLayer: "返回模拟结果: {...}"
    ToolLayer-->>ADKAgent: "收到工具结果"
    ADKAgent->>ADKAgent: "AI 模型: 转换为用户友好的回复"
    ADKAgent-->>User: "已成功创建新的货运单。您的货运单号是 SHIPMENT456。"
```
