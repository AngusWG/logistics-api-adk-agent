设备收货 equipReceipt
接口说明
通过此接口接收外接硬件设备推送的订单操作信息。

接口地址： http://www.cntodd.top//api/order/equipReceipt
请求方式： POST
请求参数

请求字段说明

字段名称 字段类型 字段长度 是否必需 字段说明 特殊说明
type String Y 扫描单号类型
Have：扫主单号（按票）
System：系统子单号
Fba：FBA箱号
Client：客户子单号
Transfer：转单子单号 		注意：此字段为API模式收货，无需登录T6系统
userid String Y 仓库收货操作人（T6系统登录名）
companycode String Y 收货公司
sitecode String Y 收货站点
token String Y 效验token
equipCode String Y 设备编号 注意：请与T6系统设备收货界面填写的设备编号保持一致，否则无法读取到数据
orderNo String Y 扫描单号
weight String Y 重量
weightunit String Y 重量单位（kg / g）默认为 g
number String Y 件数
length String Y 长（cm）
width String Y 宽（cm）
height String Y 高（cm）
childimg String N 过机拍照图片（Base64）

请求报文示例

{
    "equipCode": "EC01",
    "orderNo": "1Z64604F6796235492",
    "weight": "100",
    "weightunit": "g",
    "number": "1",
    "length": "50",
    "width": "50",
    "height": "50",
    "childimg": "/9j/4AAQSkZJRgABAQAAAQABAAD/2wBDAAgGBgcGBQgHBwcJCQgKDBQ=="
}
响应数据

响应字段说明

字段名称 字段说明
code 接口请求是否通过 0：表示接口请求通过，其他表示失败
msg 说明信息

响应数据示例

成功：
			{
			    "msg": "正常",
			    "code": "0"
			}
			失败：
			{
			    "msg": "推送数据失败，请在T6系统查看失败原因",
			    "code": "-1"
			}
