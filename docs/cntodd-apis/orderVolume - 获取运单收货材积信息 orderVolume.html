获取运单收货材积信息 orderVolume
接口说明
通过此接口可获取运单的收货材积相关信息。
重要提示：系统需包含上下游板块，否则无法正常使用该接口。

接口地址： http://www.cntodd.top//api/order/orderVolume
请求方式： POST
请求参数

请求字段说明

字段名称 字段类型 字段长度 是否必需 字段说明
authorization JSONObject
code String 5-20 Y 客户编码
token String 50 Y API授权码
datas JSONObject
waybillnumber JSONArray Y 运单号,最多一次查询20个单号，与系统单号二选一提交即可
systemnumber JSONArray Y 系统单号,最多一次查询20个单号，与运单号二选一提交即可

请求报文示例

{
    "authorization": {
        "code": "test",
        "token": "7a6a2c0d-7508-4113-9c64-037f67e7a13c"
    },
    "datas": {
        "waybillnumber": [
            "9316760611",
            "EV00000001847CN",
            "SYS211112000010"
        ]
    }
}
响应数据

响应字段说明

字段名称 字段类型 字段说明
code 接口请求是否通过 0：表示接口请求通过，其他表示失败
msg 说明信息
data JSONArray
searchNumber 查询的单号
errormsg 错误信息，若存在错误则返回
systemnumber 系统单号
waybillnumber 运单号
customernumber1 客户参考号1
forecastweight 预报重
forecastmweight 预报材重
inrweight 收货实重
inmweight 收货材重
inweight 收货结算重
square 方数
number 总件数
volumes JSONArray 收货材积
number 箱序号
prenum 件数
prelength 长
prewidth 宽
preheight 高
prerweight 单件实重
preweight 单件结算重
