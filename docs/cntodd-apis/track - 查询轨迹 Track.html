查询轨迹 Track
接口说明
通过此接口可查询系统运单的轨迹信息。

接口地址： http://www.cntodd.top//api/track
请求方式： POST
请求参数

请求字段说明

字段名称 字段类型 字段长度 是否必需 字段说明
authorization JSONObject
code String 5-20 Y 客户编码
token String 50 Y API授权码
inc String 50 轨迹事件类型编码
datas JSONObject
waybillnumber JSONArray Y 系统单号，与运单号，客户参考号三选一提交即可
示例值: [ "1Z64104F6795715591", "1Z5VT6220478322140" ]
systemnumber JSONArray Y 系统单号，与运单号，客户参考号三选一提交即可
示例值: [ "1Z64104F6795715591", "1Z5VT6220478322140" ]
customernumber JSONArray Y 系统单号，与运单号，客户参考号三选一提交即可
示例值: [ "T6241214001", "T6241214002" ]

请求报文示例

{
			    "authorization": {
			        "code": "KJHB",
			        "token": "c60bf762-01f7-470e-8c8f-acde06c81fed"
			    },
			    "datas": {
			        "waybillnumber": [
			            "EV00000001790CN",
			            "5722916732",
			        ]
			    }
			}
响应数据

响应字段说明

字段名称 字段说明
code 接口请求是否通过 0：表示接口请求通过，其他：表示失败
msg 说明信息
data
searchNumber 查件单号
errormsg 单号错误信息
systemnumber 系统单号
waybillnumber 运单号
tracknumber 转单号
countrycode 目的地国家编码
orderstatus 运单状态编码
orderstatusName 运单状态名称
trackItems 主单号轨迹 - JSONArray
trackdate 轨迹时间
trackdate_utc8 轨迹时间（东八区时间 UTC8）
location 所在地
info 轨迹说明
responsecode 响应状态码
subOrderList 子单号数组，仅展示有子单轨迹的子单号
subOrderTrackItems 子单号轨迹 JSONObject对象，key为对应的子单号
trackdate 子单号轨迹时间
trackdate_utc8 子单号轨迹时间（东八区时间 UTC8）
location 子单号所在地
info 子单号轨迹说明
responsecode 子单号响应状态码
