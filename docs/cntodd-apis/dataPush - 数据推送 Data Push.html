数据推送 Data Push
接口说明
通过此接口可推送特定数据给系统。

接口地址： http://www.cntodd.top//api/pushData
请求方式： POST
推送类目
  • 运单入仓材积信息
  • 运单出仓信息
  • 运单轨迹
  • 运单账单
  • 运单问题工单
公共请求格式

请求字段说明

字段名称 字段类型 字段长度 是否必需 字段说明
authorization JSONObject
token String Y API授权码
source String 来源，K5/T6
sign String Y 加密签名，对data数据MD5加密转大写的加密信息
data JSONObject 推送的数据内容

请求报文示例

{
			    "authorization": {
			        "token": "60bf762-01f7-470e-8c8f-acde06c81fedaabbvvasdasdas",
			        "sign": "xxx",
			        "source": "t6"
			    },
			    "data": {
			        // 推送的信息内容
			    }
			}
推送运单材积信息

请求data数据内容

字段名称 字段类型 是否必需 字段说明
systemnumber String 系统单号；系统单号、运单号、客户参考号至少提交一个
waybillnumber String 运单号；系统单号、运单号、客户参考号至少提交一个
customernumber1 String 客户参考号；系统单号、运单号、客户参考号至少提交一个
datatype String Y 提交数据类型，固定填写 orderVolume
volumes JSONArray 发货材积

prenum int 件数
prelength double 长 cm
prewidth double 宽 cm
preheight double 高 cm
prerweight double 单件实重 kg
preweight double 单件结算重 kg

{
		    "authorization": {
		        "token": "******"
		    },
		    "data": {
		        "systemnumber": "SYS220420000096",
		        "waybillnumber": "9604417255",
		        "customernumber1": "096220615000710",
		        "datatype": "orderVolume",
		        "volumes": [{
		            "number": "1",
		            "prewidth": 1,
		            "prelength": 1,
		            "preweight": 0.5,
		            "prenum": 1,
		            "preheight": 1,
		            "prerweight": 0.5
		        }]
		    }
	 }
