获取面单 Express
接口说明
通过此接口可获取面单文件。
重要提示：系统需包含上下游板块，否则无法正常使用该接口。

接口地址： http://www.cntodd.top//api/order/express
请求方式： POST
请求参数

请求字段说明

字段名称 字段类型 字段长度 是否必需 字段说明
authorization JSONObject
code String 5-20 Y 客户编码
token String 50 Y API授权码
datas JSONObject
printContent String 1：按票
2：按件（不传默认按票打印）
customernumber JSONArray Y 客户参考号1
示例值: [ "T620200611-1001", "T620200611-1002" ]

请求报文示例

{
			    "authorization": {
			        "code": "KJHB",
			        "token": "c60bf762-01f7-470e-8c8f-acde06c81fed"
			    },
			    "datas": {
			        "printContent": "1",
			        "customernumber": [
			            "T620200611-1001",
			            "T620200611-1002"
			        ]
			    }
			}
响应数据

响应字段说明

字段名称 字段说明
code 接口请求是否通过 0：表示接口请求通过，其他表示失败
msg 说明信息
data
url 面单地址
notCustomernumber 系统中不存在的单号

响应数据示例

{
			    "code": 0,
			    "msg": "调用成功",
			    "data": {
			        "url": "http://www.cntodd.top//upload/order/label/2025-02-14/53AC9F263B874B4DAC2323C9A081D23E.PDF"
			    }
			}
